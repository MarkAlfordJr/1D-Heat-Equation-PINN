# 1D-Heat-Equation-PINN

simple PINN training on JAX of a 1-dimensional Heat Equation PDE

## Problem Definition

1D Heat Equation

$$
\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}
$$

## Domains

Spatial:
x = [0,1]
Time:
